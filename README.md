A tiny Python program that writes one original funny excuse an AI agent gives after failing a task — the agent's own voice, one line, no setup wasted.

> "My planning module called a meeting with my doing module to discuss your task. Neither took notes, so now each one swears the other one was supposed to do it."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 -P -s main.py
```

This writes the excuse to `output/entry.txt` after validating it (1–200 characters, non-blank, single line).
